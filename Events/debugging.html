BugBusters

Debugging

Identify and fix errors in Python programs under time constraints. A two-round challenge that tests your precision, logic, and speed.

🔍 Spot. Fix. Conquer.

📅 Date 28 August 2026
⏰ Time 8:30 AM onwards
👥 Team Size 2 Members
💰 Registration Fee ₹150 per team

🐍 Domain: Python Debugging

All questions in both rounds are based exclusively on Python. Participants will identify and correct syntax, logical, and runtime errors in Python programs.

Syntax Errors Logical Errors Runtime Errors Python Fundamentals Code Correction Program Output

📋 Rules & Regulations

  1. The event is open to all eligible students.
  2. Each team shall consist of 2 members.
  3. All participating teams must complete their registration before the commencement of the event.
  4. Participants must arrive before 8:30 AM for registration and verification.
  5. Student ID card is mandatory.
  6. Mobile phones, smart watches, AI tools, and other electronic gadgets are strictly prohibited throughout the event.
  7. Any form of malpractice or unfair means will lead to immediate disqualification.
  8. Each team should bring their own stationery for the paper-based round.
  9. The judges' decision will be final and binding.

📝 Round 1 — Paper Fix

  1. Each team will receive a printed question paper containing Python debugging questions.
  2. Teams must identify the errors and write the corrected code in the answer sheet provided.
  3. Laptop, mobile phone, and internet usage are not permitted during this round.
  4. Discussion between team members is allowed.
  5. The top-scoring teams will qualify for Round 2.
10 Questions
30 min Duration
Easy–Med Difficulty
None Negative Marking

🏆 Round 2 — Live Debugging

  1. Qualified teams will perform debugging using the computer system provided.
  2. Three Python files containing multiple errors will be available on the system.
  3. Teams must identify and fix all the errors to produce the expected output.
  4. Corrected files must be saved and submitted before the time limit.
3 Python Files
30 min Duration
Med–Hard Difficulty
